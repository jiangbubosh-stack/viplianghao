# 部署成公网网址（无需服务器）

本目录下的 `index.html` 是一个**纯静态单文件**，不依赖任何后端，可部署到任意静态托管平台，拿到所有人都能访问的公网网址。

## 第一步：准备你的号码（本地后台）

1. 用浏览器打开 `index.html` → 点右上角「管理后台」。
2. 密码默认 `admin888`（改密码编辑文件顶部 `var ADMIN_PASSWORD`）。
3. 上传 / 粘贴 / 单个添加你的手机号码。
4. 点右上角 **「导出发布版」** → 浏览器下载一个新的 `index.html`（里面已经**烤进了你所有的号码**）。

> 之后每次增删号码，重复第 3–4 步重新导出即可。

## 第二步：部署（三选一，均免费）

### 方式 A：Netlify Drop（最快，拖一下就行）
1. 打开 https://app.netlify.com/drop
2. 把导出的 `index.html` **拖进去**
3. 立刻得到一个 `https://xxxx.netlify.app` 网址，发给谁都能打开 ✅

### 方式 B：Cloudflare Pages
1. 打开 https://pages.cloudflare.com → 用 GitHub 登录
2. 新建项目 → 直接上传 `index.html`（或关联仓库）
3. 构建命令留空，输出目录填 `.` → 部署
4. 得到 `https://xxxx.pages.dev` 网址

### 方式 C：GitHub Pages
1. 新建一个 GitHub 仓库，把 `index.html` 推上去（需重命名为 `index.html` 放在根目录）
2. Settings → Pages → Source 选 `main` 分支根目录 → Save
3. 等待 1 分钟，得到 `https://你的用户名.github.io/仓库名` 网址

## 重要提醒
- **隐私合规**：公开展示的手机号请确保是你**自有或已授权**的号源，避免上传他人真实号码造成合规风险。
- **数据互通**：号码已烤进文件，访客看到的是同一个版本；改号码后必须重新「导出发布版」并重新部署。
- **后台密码**：部署出去的文件含后台登录入口，请务必改成你自己的密码。

## 端口 / 本地自测
本地双击 `index.html` 即可在浏览器打开，无需任何服务器。
